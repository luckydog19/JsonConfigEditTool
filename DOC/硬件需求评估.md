## 📋 执行环境概述

JsonEditTool 是一个基于 Python 的命令行工具，已编译为 Windows 可执行文件（EXE），用于快速编辑 JSON 配置文件。

---

## 💻 最低硬件要求

### 处理器 (CPU)
- **架构**: x86-64 (64位)
- **最低配置**: 任意支持 Windows 7+ 的单核处理器
- **推荐配置**: Intel Pentium 4 或同等级别以上
- **频率要求**: ≥ 1.0 GHz

**说明**: 本工具为轻量级命令行工具，主要执行 JSON 文件解析和字符串操作，CPU 负载极低。

---

### 内存 (RAM)
- **最低配置**: 64 MB 可用内存
- **推荐配置**: 128 MB 可用内存
- **典型占用**: 
  - 冷启动: ~20 MB
  - 处理小文件(<1MB): 20-30 MB
  - 处理中等文件(1-10MB): 30-50 MB
  - 处理大文件(>10MB): 50-100 MB

**说明**: 工具采用一次性读写策略，内存占用主要取决于 JSON 文件大小。

---

### 存储空间 (Disk)
- **程序文件大小**: 7.28 MB (JsonEditTool.exe)
- **日志文件空间**: 建议预留 10-50 MB
  - 单个日志文件: 每天约 1-5 MB（取决于操作频率）
  - 日志保留策略: 建议定期清理旧日志
- **临时空间**: 10 MB（备份文件、临时处理）
- **总计推荐**: 100 MB 可用空间

**目录结构**:
```
工作目录/
├── JsonEditTool.exe        (7.28 MB)
├── jsonedittoollogs/       (日志目录)
│   └── json_edit_tool_*.log
└── config备份/              (可选备份目录)
```

---

### 磁盘 I/O 性能
- **最低要求**: 传统机械硬盘 (HDD) 即可满足
- **推荐配置**: 固态硬盘 (SSD) 可提升大文件处理速度
- **典型 I/O 操作**:
  - 文件读取: 一次性加载
  - 文件写入: 一次性覆盖
  - 备份操作: 文件复制

## 🔧 优化建议

### 低配环境优化
1. **减少日志输出**: 使用 `--silent` 模式（默认启用）
2. **避免大文件**: 超过 10 MB 的 JSON 文件考虑拆分
3. **禁用备份**: 不使用 `--backup` 参数节省磁盘空间
4. **定期清理日志**: 删除过期的日志文件

### 高性能环境优化
1. **使用 SSD**: 提升大文件读写速度
2. **批量操作**: 合并多次修改为一次批处理
3. **脚本自动化**: 减少人工交互延迟

## 🚨 限制和注意事项

### 硬件限制
1. **内存限制**: 处理超大 JSON 文件（>100MB）可能导致内存不足
2. **磁盘空间**: 日志文件会累积，需定期清理
3. **文件系统**: 需要支持文件锁定和原子写入

### 性能瓶颈
1. **JSON 解析**: Python 标准库性能有限
2. **单线程**: 无并行处理能力
3. **文件 I/O**: 受磁盘速度限制

### 推荐解决方案
- 大文件: 考虑拆分或使用专业工具
- 高并发: 部署多个实例
- 性能要求: 使用 SSD + 充足内存
